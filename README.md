Personal Portfolio

Project Overview

This project is a personal portfolio website built as my CS50x Final Project. It is a web application designed to present the most important information about me in a clean, organized, and convenient way. The website brings together information about my education, technical skills, projects, and background, while also providing visitors with an easy way to contact me.

I created this project primarily to practice and strengthen my knowledge of HTML, CSS, Python, and Flask. At the same time, I wanted the result to be useful beyond the scope of the course. The portfolio is intended to serve as my personal website, which I can share online when applying for internships, jobs, or other opportunities.

The main target audience of the website is recruiters and people who would like to learn some basic information about me or get in touch with me. The website therefore focuses on presenting information clearly rather than implementing unnecessary complex functionality.

Technologies

The project was developed using the following technologies:

Python – used as the main programming language.
Flask – used as the web framework responsible for routing and rendering the pages.
Jinja – used for templating and sharing common HTML structures between pages.
HTML5 – used to create the structure and content of the website.
CSS3 – used for styling, layout, responsiveness, and visual design.
Bootstrap 5 – used mainly for the responsive navigation bar and some basic layout functionality.
Font Awesome – used for social media icons.
Formspree – used to process contact form submissions without requiring a separate mail server or database.

Project Structure

The main Python application is stored in app.py. It creates the Flask application and defines the routes for all pages of the website. Each route renders the appropriate Jinja template.

The templates directory contains all HTML templates.

layout.html is the base template shared by the other pages. It contains the common structure of the website, including the navigation bar, external libraries, and other elements that should remain consistent throughout the website. Jinja template inheritance is used so that individual pages do not need to duplicate the same layout.

index.html is the homepage. It introduces me to visitors and provides links to my CV and other relevant sections of the portfolio.

about.html contains information about me and provides a short introduction to my background and interests.

skills.html presents my technical skills and the technologies I have experience with.

projects.html presents selected projects and gives visitors an overview of the work I have completed.

education.html contains information about my education, including my secondary school, university studies, certificates, and courses.

contact.html contains the contact form. The form uses Formspree to process submissions. After a successful submission, the user receives a confirmation message without being redirected to a separate page. The page also contains links to my GitHub and LinkedIn profiles.

The static directory contains files that do not need to be dynamically generated by Flask. styles.css contains the custom styling used throughout the website. The static/images directory contains images used by the portfolio, while static/cv contains the Polish and English versions of my CV.

Finally, requirements.txt contains the Python dependencies required to run the project.

Functionality

The website consists of several connected pages that can be accessed through the navigation bar. Flask handles the routing between these pages, while Jinja allows them to share a common layout.

The website is responsive, meaning that its layout changes depending on the size of the user's screen. Particular attention was given to the navigation bar and page layouts on smaller screens. For example, the navigation menu changes into a collapsible menu at smaller screen widths, while content sections adjust their layout to remain readable.

The contact page provides an actual way for visitors to send a message. Formspree handles the form submission, while the website displays a success message after a successful submission. This allowed me to implement contact functionality without creating my own email server or storing submitted messages in a database.

The homepage also provides downloadable versions of my CV, allowing visitors to quickly access more detailed information about my education and experience.

Design Decisions

One of the main decisions I made was to use Flask instead of creating a completely static website. I wanted to practice Python and understand how a web framework connects routes with HTML templates. Flask was appropriate for the size of the project because it provides the functionality I needed without introducing unnecessary complexity.

I also decided to use Jinja template inheritance. Since all pages share the same navigation and general structure, keeping this code in layout.html makes the project easier to maintain. Changes to the shared layout can be made in one place instead of being repeated across every page.

I considered using a database such as SQLite, but ultimately decided that it was unnecessary for this version of the portfolio. The content of the website is mostly static and does not require users or an administrator to modify it through the application. Removing the database also kept the project focused on its main purpose and allowed me to concentrate on Flask, HTML, CSS, and responsive design.

For the contact form, I chose Formspree instead of implementing my own email-handling system. A custom email system would require additional infrastructure and would introduce functionality that was not essential to the portfolio. Formspree allowed me to provide a functional contact form while keeping the application simple.

I used Bootstrap together with custom CSS. Bootstrap was useful for parts of the responsive navigation, while writing my own CSS allowed me to control the appearance and layout of the portfolio instead of relying entirely on a predefined framework design.

Running the Project

To run the project locally, Python must be installed on the computer.

First, create and activate a virtual environment:


python -m venv venv


On Windows PowerShell, activate it with:


.\venv\Scripts\Activate.ps1


Install the required dependencies:


pip install -r requirements.txt


Then start the Flask application:


python app.py


The application will start a local development server that can be accessed through the address displayed by Flask in the terminal.

Conclusion

This project allowed me to combine the knowledge I gained throughout CS50x with additional independent work on Flask, HTML, CSS, Jinja, and responsive web design. More importantly, it resulted in a functional portfolio that can be used as a real personal website rather than only as a course assignment.

The project can be extended in the future with additional projects, improved animations, further responsive design improvements, and deployment to a public web server. For its current purpose, however, the main goal is to provide a simple and professional way to present information about me and allow potential recruiters or other visitors to contact me.
